### 🔧 Конфигурация для продакшена

**Основной файл:** `configs/proxy.yaml`
```yaml
listen: ":1080"
log_level: "info"

rules:
  # Домены доступные напрямую
  - domain: "*.github.com"
    pipeline: {}
  
  # Соцсети (требуют обхода)
  - domain: "*.facebook.com"
    pipeline:
      fragmentation:
        min_size: 64
        max_size: 128
        random: true
      headers:
        random_headers: true
        modify_host: true
      encryption:
        type: "xor"
        key: "secure_key"
```

### 📱 Настройка клиентов

**Firefox:**
- Settings → Network Settings → Manual proxy configuration
- SOCKS Host: 127.0.0.1, Port: 1080

**Chrome/Chromium:**
```bash
google-chrome --proxy-server="socks5://127.0.0.1:1080"
```

**Системные настройки:**
```bash
export ALL_PROXY=socks5://127.0.0.1:1080
```

### 🚨 Траблшутинг

**Общие проблемы и решения:**
1. **Порт занят** - `sudo lsof -i :1080`
2. **Нет соединения** - проверить настройки сети
3. **Медленная работа** - упростить правила пайплайнов
4. **DPI не обходит** - настроить другие модификаторы
