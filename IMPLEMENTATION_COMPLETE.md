### 🔧 Конфигурация для продакшена

**Основной файл:** `configs/proxy.yaml`
```yaml
listen: ":1080"
log_level: "info"

rules:
  # Домены доступные напрямую
  - domain: "*.github.com"
    pipeline: {}
  
  # Соцсети (требуют обхода)
  - domain: "*.facebook.com"
    pipeline:
      fragmentation:
        min_size: 64
        max_size: 128
        random: true
      headers:
        random_headers: true
        modify_host: true
      encryption:
        type: "xor"
        key: "secure_key"
```
