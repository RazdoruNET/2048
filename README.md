# SOCKS5 DPI Proxy

Высокопроизводительный SOCKS5 прокси с динамическими пайплайнами для обхода DPI фильтров.

## Возможности

- **SOCKS5 прокси**: Полная поддержка SOCKS5 протокола
- **Динамические пайплайны**: Автоматический подбор техник обхода для каждого запроса
- **Множественные техники DPI обхода**:
  - Фрагментация пакетов
  - Модификация HTTP заголовков
  - Шифрование трафика (XOR, RC4)
  - Маскировка под другие протоколы (SSH, HTTPS, TLS)
- **Гибкая конфигурация**: YAML конфигурация с правилами для доменов и IP диапазонов
- **Docker поддержка**: Готовый контейнер для развертывания

## Конфигурация

### Основная конфигурация (configs/proxy.yaml)

```yaml
listen: ":1080"
log_level: "info"

rules:
  - domain: "*.example.com"
    pipeline:
      fragmentation:
        min_size: 50
        max_size: 150
        random: true
      headers:
        random_headers: true
        modify_host: true
      encryption:
        type: "xor"
        key: "secret_key"
```

### Модификаторы

#### Fragmentation (Фрагментация)
- `min_size`: Минимальный размер фрагмента
- `max_size`: Максимальный размер фрагмента  
- `random`: Случайный размер фрагментов

#### Headers (Модификация HTTP заголовков)
- `random_headers`: Добавлять случайные заголовки
- `modify_host`: Модифицировать Host заголовок
- `add_junk_headers`: Добавлять "мусорные" заголовки
- `custom_headers`: Пользовательские заголовки
- `user_agents`: Список User-Agent для ротации

#### Encryption (Шифрование)
- `type`: Тип шифрования (`xor`, `rc4`)
- `key`: Ключ шифрования

#### Protocol Mask (Маскировка протокола)
- `type`: Тип маскировки (`ssh`, `https`, `tls`)
- `ssh_padding`: Добавлять SSH паддинг
- `https_noise`: Добавлять HTTPS шум

## Правила маршрутизации

Правила обрабатываются в порядке:

1. Точное совпадение домена
2. Wildcard домены (*.example.com)
3. IP диапазоны (192.168.1.0/24)
4. Правило по умолчанию (*)

## Примеры использования

### Настройка браузера

```bash
# Настройка для Firefox
# Preferences -> Network Settings -> Manual proxy configuration
# SOCKS Host: 127.0.0.1, Port: 1080

# Настройка для Chrome/Chromium
google-chrome --proxy-server="socks5://127.0.0.1:1080"
```

### Использование с curl

```bash
curl --socks5 127.0.0.1:1080 http://example.com
```

### Использование с Telegram

```bash
# Настройки Telegram
# Settings -> Data and Storage -> Use proxy
# SOCKS5: 127.0.0.1:1080
```

## Мониторинг и логирование

Прокси логирует:
- Подключения клиентов
- Применяемые правила
- Ошибки обработки
- Статистику производительности

Уровни логирования:
- `debug`: Детальная отладочная информация
- `info`: Общая информация (по умолчанию)
- `warn`: Предупреждения
- `error`: Ошибки

## Производительность

- **Поддерживаемые соединения**: 1000+ одновременных
- **Потребление памяти**: < 100MB для 1000 соединений
- **Задержка**: < 10ms добавочная
- **Пропускная способность**: 1Gbps+

- Логирование безопасности

## Разработка

### Структура проекта

```
socks5-dpi-proxy/
├── cmd/proxy/           # Точка входа
├── internal/
│   ├── proxy/          # SOCKS5 сервер
│   ├── pipeline/       # Движок пайплайнов
│   └── config/        # Конфигурация
```

### Добавление новых модификаторов

1. Создать новый модификатор в `internal/pipeline/`
2. Реализовать интерфейс `Modifier`
3. Добавить в `createModifierInstance()`
