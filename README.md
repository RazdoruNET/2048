## 🚨 План исправления обхода DPI

Этот план детализирует критическое исправление, необходимое для системы обхода DPI, где фрагментация не работает на сетевом уровне из-за некорректной архитектуры в ModifiedConnection.Write.

### Проблема
Текущая архитектура в `connection_v2.go:115-155` выполняет ОДИН вызов `Conn.Write(chunk)` для каждого фрагмента, но все фрагменты объединяются в один MTU пакет на уровне TCP стека. DPI видит оригинальный пакет → обход не работает.

### Решение
Реализовать реальные задержки между фрагментами и обеспечить отдельные TCP сегменты для каждого фрагмента.
